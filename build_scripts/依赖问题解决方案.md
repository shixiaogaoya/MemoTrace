# MemoTrace 打包依赖问题解决方案

## 概述
本文档详细说明了在打包 MemoTrace 过程中可能遇到的各种依赖问题及其解决方案。

## 常见依赖问题

### 1. pywin32 安装失败

**问题描述：**
```
ERROR: Could not find a version that satisfies the requirement pywin32==308
```

**解决方案：**
```bash
# 方案1：使用conda安装（推荐）
conda install pywin32

# 方案2：从官网下载wheel文件
pip install --find-links https://github.com/mhammond/pywin32/releases pywin32

# 方案3：使用特定版本
pip install pywin32>=227

# 方案4：手动下载安装
# 访问：https://github.com/mhammond/pywin32/releases
# 下载对应Python版本的wheel文件，然后：
pip install 下载的wheel文件名
```

### 2. yara-python 安装问题

**问题描述：**
```
ERROR: Failed building wheel for yara-python
```

**解决方案：**
```bash
# 方案1：安装预编译版本
pip install yara-python-legacy

# 方案2：使用conda
conda install -c conda-forge yara-python

# 方案3：Windows用户下载预编译wheel
pip install --find-links https://github.com/VirusTotal/yara-python/releases yara-python

# 方案4：跳过此依赖（如果不需要YARA功能）
# 编辑requirements.txt，删除或注释掉yara-python行
```

### 3. lxml 编译错误

**问题描述：**
```
ERROR: Microsoft Visual C++ 14.0 is required
```

**解决方案：**
```bash
# 方案1：安装预编译版本
pip install --upgrade pip
pip install lxml

# 方案2：使用conda
conda install lxml

# 方案3：安装Visual C++构建工具
# 下载并安装Microsoft C++ Build Tools
# 网址：https://visualstudio.microsoft.com/visual-cpp-build-tools/

# 方案4：使用wheel文件
pip install --find-links https://pypi.org/simple/ lxml
```

### 4. Pillow 安装问题

**问题描述：**
```
ERROR: Could not build wheels for Pillow
```

**解决方案：**
```bash
# 方案1：升级pip和setuptools
pip install --upgrade pip setuptools wheel
pip install Pillow

# 方案2：指定版本
pip install Pillow>=8.0.0

# 方案3：使用conda
conda install pillow

# 方案4：从源码安装（需要相关依赖）
pip install --upgrade pip
pip install --force-reinstall Pillow
```

### 5. cryptography 安装问题

**问题描述：**
```
ERROR: Failed to build cryptography
```

**解决方案：**
```bash
# 方案1：升级pip和安装Rust
pip install --upgrade pip
# 访问 https://rustup.rs/ 安装Rust，然后：
pip install cryptography

# 方案2：使用预编译版本
pip install --only-binary=cryptography cryptography

# 方案3：使用conda
conda install cryptography

# 方案4：降级到兼容版本
pip install cryptography==3.4.8
```

## 环境配置建议

### 1. 推荐的Python版本
```
Python 3.10.x （官方GitHub Action使用的版本）
Python 3.9.x  （兼容性良好）
Python 3.11.x （较新，可能有兼容性问题）
```

### 2. 虚拟环境设置
```bash
# 创建虚拟环境
python -m venv memotrace_env

# 激活虚拟环境
# Windows:
memotrace_env\Scripts\activate
# Linux/Mac:
source memotrace_env/bin/activate

# 升级基础工具
pip install --upgrade pip setuptools wheel

# 安装依赖
pip install -r requirements.txt
```

### 3. 依赖安装顺序建议
```bash
# 1. 先安装基础依赖
pip install wheel setuptools pip --upgrade

# 2. 安装系统级依赖
pip install pywin32 psutil

# 3. 安装编译依赖（可能需要编译环境）
pip install lxml cryptography yara-python

# 4. 安装其他依赖
pip install pillow openpyxl requests beautifulsoup4

# 5. 最后安装剩余依赖
pip install -r requirements.txt
```

## 打包工具特定问题

### PyInstaller 问题

**问题1：模块未找到**
```python
# 在spec文件中添加隐藏导入
hiddenimports = [
    'win32api',
    'win32con',
    'pywintypes',
    '缺失的模块名'
]
```

**问题2：数据文件丢失**
```python
# 在spec文件中添加数据文件
datas = [
    ('源路径', '目标路径'),
    ('exporter/resources', 'exporter/resources'),
]
```

### Nuitka 问题

**问题1：模块导入错误**
```bash
# 添加模块包含参数
--include-module=模块名
--include-package=包名
```

**问题2：数据文件问题**
```bash
# 添加数据文件参数
--include-data-file=源文件=目标路径
--include-data-dir=源目录=目标目录
```

### cx_Freeze 问题

**问题1：缺失依赖**
```python
# 在setup文件中添加包
packages = [
    '缺失的包名',
    'win32api',
    'pywintypes'
]
```

## 系统环境修复

### Windows 环境修复

**1. 安装 Visual C++ Redistributable**
```
下载并安装：
- Microsoft Visual C++ 2015-2022 Redistributable (x64)
- Microsoft Visual C++ 2015-2022 Redistributable (x86)
```

**2. 修复 Windows 组件**
```cmd
# 以管理员身份运行命令提示符
sfc /scannow
DISM /Online /Cleanup-Image /RestoreHealth
```

**3. 更新 Windows**
```
确保系统更新到最新版本，特别是：
- .NET Framework 4.8
- Windows SDK
- 最新的安全更新
```

### Python 环境修复

**1. 重新安装 Python**
```bash
# 完全卸载现有Python
# 从官网下载最新版本Python
# 安装时确保勾选：
# - Add Python to PATH
# - Install pip
# - Install for all users（如果有管理员权限）
```

**2. 清理pip缓存**
```bash
pip cache purge
pip install --upgrade pip
```

## 问题排查步骤

### 1. 基础检查
```bash
# 检查Python版本
python --version

# 检查pip版本
pip --version

# 检查已安装包
pip list

# 检查特定包
pip show 包名
```

### 2. 依赖冲突检查
```bash
# 检查依赖冲突
pip check

# 查看包的依赖关系
pip show --verbose 包名
```

### 3. 重新安装问题包
```bash
# 卸载有问题的包
pip uninstall 包名

# 清理缓存
pip cache purge

# 重新安装
pip install 包名 --no-cache-dir
```

## 应急备选方案

### 1. 使用conda替代pip
```bash
# 安装Anaconda或Miniconda
# 创建conda环境
conda create -n memotrace python=3.10
conda activate memotrace

# 使用conda安装依赖
conda install pywin32 psutil pillow lxml cryptography
pip install 其他剩余依赖
```

### 2. 使用Docker（高级用户）
```dockerfile
FROM python:3.10-windowsservercore

WORKDIR /app
COPY requirements.txt .
RUN pip install -r requirements.txt

COPY . .
RUN pip install pyinstaller
RUN pyinstaller --onefile example/3-exporter.py
```

### 3. 使用GitHub Actions构建
```yaml
# 修改.github/workflows/build-exe.yml
# 在自己的fork中运行，下载生成的artifacts
```

## 总结

大多数依赖问题都可以通过以下方式解决：
1. 使用正确的Python版本（3.10推荐）
2. 创建干净的虚拟环境
3. 按正确顺序安装依赖
4. 使用预编译版本替代编译安装
5. 在必要时降级到兼容版本

选择最适合自己系统环境的解决方案，通常都能成功完成打包。
